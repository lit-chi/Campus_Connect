# CampusConnect

**CampusConnect** is an all-in-one platform designed to enhance the student experience by integrating key academic and social features into a single, accessible interface.

## 🌐 Overview

CampusConnect streamlines student life by offering a centralized platform for academic collaboration, peer support, resource sharing, and event coordination—eliminating the need to rely on multiple tools.

## 🚀 Features

- **Q&A Forum** – A space for students to ask and answer academic or college-related questions.
- **Resources** – Access to previous year papers, study materials, and a marketplace for second-hand academic items. Also includes updates on college events.
- **Events** – Promote and coordinate college fests, workshops, and student-led activities.

## 🛠️ Tech Stack

- **Frontend:** JavaScript, React.js (UI), CSS  
- **Backend:** MongoDB
